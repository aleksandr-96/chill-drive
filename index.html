Chill Drive

A personal storage connection between the owner's server and the owner's Google Drive, powered by rclone.

Purpose

Chill Drive lets its owner store and retrieve archives and backups in a dedicated chill folder. It is a private, single-user utility, not a public file-sharing or storage service.

Google Drive access

The application requests only https://www.googleapis.com/auth/drive.file. It can create files and read, update or delete files authorized for this application. It does not request unrestricted access to the owner's entire Drive.

Authorization is handled by Google. This website has no sign-in form and does not receive Google passwords or OAuth credentials.

Data and support

Read the privacy policy and terms of use. For general questions, contact the maintainer through GitHub issues. Never post credentials or private file contents.
