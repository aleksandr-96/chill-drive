Privacy policy

This policy describes the personal Chill Drive application operated by the GitHub account aleksandr-96.

Data accessed and purpose

Chill Drive uses Google's drive.file permission to manage files created by or explicitly authorized for this application. It processes file contents and metadata, including names, identifiers, sizes and modification times, to upload, list, download, update and delete the owner's archives and backups. Storage quota information may be read to report available capacity.

Storage and security

Files are stored in the owner's Google Drive. Transfers and any local archive copies are processed on the owner's server. OAuth client credentials and refresh tokens are stored in restricted configuration files on that server. Operational logs may contain file names, paths and transfer errors. Credentials and private files are not published on this website or its source repository.

Sharing and use limitations

Google processes Drive data to provide its service; the owner's hosting provider supplies the server infrastructure. Chill Drive does not sell Google user data, use it for advertising, or use it to train AI models. Data is used only for the personal storage functions described here. Chill Drive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, deletion and revocation

The owner controls retention and can delete cloud files in Google Drive and local copies on the server. Revoking access through Google Account connections stops future authorized access but does not itself delete existing files or local copies. Credentials can also be removed from the server. Google Drive's own trash and retention rules apply to deleted cloud files.

This website

These informational pages are hosted by GitHub Pages. No application analytics, tracking scripts or cookies are added by these pages. GitHub may process technical request data under its own privacy statement.

Contact and changes

General privacy questions can be raised through the project issue tracker. Do not include private data, tokens or secrets in public issues. This page will be updated if the application's data practices change.
